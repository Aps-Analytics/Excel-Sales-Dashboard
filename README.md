
Interactive Online Sales Dashboard

Project Overview

An interactive sales dashboard created using Microsoft Excel to analyze online sales performance and present key business insights.

Tools Used

- Microsoft Excel
- Pivot Tables and Pivot Charts
- Lookup Functions
- Slicers
- Data Analysis and Visualization

Dashboard Features

- Key Performance Indicators (KPIs)
- Monthly Revenue Trend
- Revenue by Product Category
- Revenue by Region
- Units Sold by Payment Method
- Top 5 Products by Units Sold
- Interactive filters for Region, Product Category, Payment Method, and Month

Project Objective

To practice Excel data analysis and transform sales data into meaningful visual insights using an interactive dashboard.

Files Included

- Excel workbook
- Dashboard screenshot

Skills Demonstrated

Excel, Data Analysis, Data Visualization, Pivot Tables, Pivot Charts, Lookup Functions, and Dashboard Creation.
